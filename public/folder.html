第一次使用：如何下载 ZIP？

X 官方存档
  1. 在已登录的 X 中打开 更多 → 设置和隐私 → 你的账号 → 下载你的数据存档。
  2. 按 X 提示确认密码或完成身份验证，点击申请存档。
  3. 等待 X 的邮件或站内通知；准备好后，在已登录 X 的浏览器里下载 .zip 文件。准备存档可能需要几天，不会立即下载。
  4. 把下载完成的 ZIP 放进下面的 archives 文件夹，无需解压，再点“刷新文件夹”。也可以在 Chrome 的“另存为”窗口直接选择此文件夹。
