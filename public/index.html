CHROME EXTENSION · VERSION 2.1

导入两份名单，离线比较。

默认导入官方存档，无需登录或打开 X。
比较过程不滚动页面、不自动访问 X。

首次安装，只需一次

无需启动服务器
  1. 在 Chrome 地址栏输入 chrome://extensions。
  2. 打开右上角“开发者模式”，点击“加载已解压的扩展程序”。
  3. 选择下面这个文件夹（必须选到包含 manifest.json 的 extension 目录）：

    __EXTENSION_DIRECTORY__

  4. 在任意页面点击 Chrome 工具栏的“回关检查”。
  5. 在新标签页选择存档中的 following.js 和 follower.js，点击“本地比较名单”。

请先通过 X 设置下载账号存档，解压后从 data 文件夹选取名单；有分片时请选全同一次存档的文件。现有扩展需到 chrome://extensions 重新加载。

↔

以后只需：点击扩展 → 导入名单 → 本地比较

不需要运行本地服务，也不需要授权登录。结果对应存档状态，不是实时名单。

只读取关系，不执行取关。不提取 Cookie · 不关闭 Chrome

本页面是安装指引。普通本地网页不能直接读取另一个 Chrome 标签页的 X 登录状态。
