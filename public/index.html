CHROME EXTENSION · VERSION 2.3

点击扩展，直接看名单。

默认读取项目 archives 文件夹，无需选择单个名单。
比较过程不滚动页面、不自动访问 X。

首次安装，只需一次

先启动本地工具
  1. 在 Chrome 地址栏输入 chrome://extensions。
  2. 打开右上角“开发者模式”，点击“加载已解压的扩展程序”。
  3. 选择下面这个文件夹（必须选到包含 manifest.json 的 extension 目录）：

    __EXTENSION_DIRECTORY__

  4. 在任意页面点击 Chrome 工具栏的“回关检查”。
  5. 双击项目的 启动工具.command，把存档 ZIP 放进 archives；点击扩展即可打开名单。

请先通过 X 设置下载账号存档。支持直接放入 ZIP，无需解压；自动选择最近修改的一份，也可手动切换。现有扩展需重新加载并确认版本为 2.3.0，关闭旧页面后再次点击图标；如 Chrome 要求确认本机访问权限，请确认。
