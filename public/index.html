↗ 回关检查FOR X 复用现有 Chrome 登录
CHROME EXTENSION · VERSION 2

登录已经有了，直接用。

新版会自动识别当前 X 账号，无需填写用户名或重复登录。
首次加载扩展后，在你已有的 X 标签页点击扩展图标即可。

首次安装，只需一次

无需启动服务器
  1. 在 Chrome 地址栏输入 chrome://extensions。
  2. 打开右上角“开发者模式”，点击“加载已解压的扩展程序”。
  3. 选择下面这个文件夹（必须选到包含 manifest.json 的 extension 目录）：

    __EXTENSION_DIRECTORY__

  4. 回到已经登录的 x.com 标签页，点击 Chrome 工具栏的“回关检查”。
  5. 工具自动显示你的账号，点击“扫描我的未回关”。

首次连接可能刷新 X 页面以载入扩展，不会退出登录。扫描在原 X 标签页自动翻页，完成后恢复原页面。

↔

以后只需：打开 X → 点击扩展 → 扫描

不需要运行这个本地服务，也不需要再授权登录。

只读取关系，不执行取关。不提取 Cookie · 不关闭 Chrome

本页面是安装指引。普通本地网页不能直接读取另一个 Chrome 标签页的 X 登录状态。
