# 回关检查 · 本地存档工具 v3.0.0

**下载 X 存档 ZIP → 放进 `archives` → 双击「启动工具.command」→ 查看未回关名单。**

## 如何下载 ZIP

1. 在已登录 X 的“更多 → 设置和隐私 → 你的账号 → 下载你的数据存档”中申请存档，按 X 提示完成身份验证。
2. 等待邮件或站内通知，准备存档可能需要几天。
3. 在已登录 X 的浏览器里下载 ZIP。[X 官方下载说明](https://help.x.com/en/managing-your-account/how-to-download-your-x-archive)。
4. 将下载完成的 ZIP 放到本项目的 **archives** 文件夹，无需解压。也可以在 Chrome 的“另存为”窗口直接选择此文件夹。

## 启动与使用

需要 **Node.js 20+**；直接读取 ZIP 另需 **Python 3**，仅使用标准库，无需安装 Python 包。日常使用不需要运行 npm install。

双击项目中的 **启动工具.command**，会启动本机服务，并打开存档文件夹及名单页面。也可在项目目录运行 `npm start`，地址固定为 `http://127.0.0.1:59931/`。保持启动终端打开；按 Control+C 或关闭终端可停止服务。重复启动会复用正在运行的同一工具。

打开页面或点击“刷新文件夹”会自动选择最近修改的一份存档，也可用下拉框手动切换其他存档。支持账号 ID / 用户名 / 名称搜索、分页、主页链接和 CSV 导出。页面已打开时，放入文件后点击刷新即可。

也支持解压后的 `archives/data`、`archives/存档文件夹/data`，或直接将 `following.js` / `follower.js` 及其全部分片放入 `archives`。多份存档分开处理，不会合并。

## 文件与隐私

只读取 ZIP 文件目录及精确匹配的关注、粉丝名单条目，不整体解压，不读取私信、媒体或其他账号资料的内容。不执行存档中的 JavaScript，只解析其中的 JSON 文本。

比较过程不访问 X、不读取登录态、不上传存档。打开或刷新页面会读取本地用户名缓存；仅点击用户名查询按钮时，向 X 的公开时间线组件发送待查询的数字账号 ID，不发送名单文件、不使用浏览器登录态或 API Key。点击外链会打开对应网站。服务仅监听 `127.0.0.1`，名单接口拒绝跨源访问；存档文件不作为网页文件提供。`archives` 内的个人数据已被 Git 忽略，不会提交到 GitHub。

## 限制

结果仅反映存档生成时的关系，不是当前实时状态。请使用同一次完整存档；工具无法判断末尾是否遗漏分片。缺少用户名时显示账号 ID 并提供 ID 主页链接；可点击“查询缺失用户名”联网补全，手动操作前仍应打开主页核对。

名单按字符串 ID 去重，保留大整数精度；两份名单合计上限 100 MB，单份名单最多 1,000,000 条。缺失或重复分片、损坏 JSON、无效 ID、加密名单、符号链接及一个 ZIP 内包含多组名单时拒绝生成结论。

## 开发验收

运行 `npm install`、`npx playwright install chromium` 后运行 `npm test`。Playwright 仅用于开发验收，使用临时浏览器与合成存档，不读取现有浏览器配置或真实账号数据。不创建或运行单元测试；实现结束后集中执行完整集成验收。

运行代码位于 `src/server.mjs`、`src/archive-folder.mjs`、`src/archive.mjs`、`scripts/read-archive-zip.py` 和 `public/`。

## 无需 Key 的用户名查询与缓存

比较完成后，点击 **查询缺失用户名**：只查询当前未回关名单中缺失用户名的账号，每批 3 个，逐个保存。查询期间可点击停止，当前小批结束后停止；断网或限流时保留已查结果。

成功查询的账号 ID、用户名、昵称和查询时间保存到 `archives/.profile-cache/user-profiles.json`，跨刷新、重启、存档复用，不自动过期或重复联网。账号改名后可点击 **更新全部用户名** 手动更新当前名单；更新失败会保留原缓存。未取得用户名的账号等待 24 小时后，点击查询才会重试；手动更新可提前重试。连接失败或限流会暂停联网 5 分钟。

公开数据来自 `https://syndication.twitter.com/srv/timeline-profile/user-id/<ID>`。这是 X 的公开网页组件，并非正式、保证可用的用户查询 API；私密、停用、无公开时间线或受限账号可能无法获取。页面格式变化、网络限制时会明确提示，继续显示 ID。公开资料可能存在延迟。

需要系统 `curl`（macOS 自带），会沿用系统进程的代理环境变量，但不读取 `.curlrc`、浏览器配置或凭据文件。缓存为本地隐私数据，继承 `archives` 的 Git 忽略规则，也不会由静态文件服务暴露。移走缓存文件即可清空已存用户名；损坏缓存会报告错误并保留原文件。
