# 独立临时 mihomo 实施计划

**目标：** X-Follow-Checker 启动时复用已确认的 Homebrew 节点缓存，使用应用独立代理，限流后有上限地换节点。

**架构：** Node 管理本机控制器和显式 curl 代理。Python 读取本地 YAML、创建隔离快照并监督 mihomo；Node 退出导致 stdin EOF，监督进程清理核心与临时目录。

**约束：** 不输出或提交凭据；不改常驻核心或系统代理；代理失败不直连；保留七天资料缓存；所有实现结束后统一执行完整验收，不在实施期间创建或运行单元测试。

- [x] `scripts/mihomo-runtime.py`：本地快照、禁用订阅刷新/TUN/额外监听，监督与退出清理。
- [x] `src/proxy.mjs`：随机本机端口、控制器认证、每次至少两秒间隔、429 后十五秒等待、半小时最多换两次。
- [x] `src/profiles.mjs`：注入资料/头像传输，标识 HTTP 429，保留原解析与缓存。
- [x] `src/server.mjs` 与 `public/local.js`：启动/停止管理、版本检查、无直连回退和查询进度。
- [x] README 与最终完整验收：缓存、代理隔离、换节点上限、退出清理、旧版检测。完成后创建本地提交，不推送。

**复核重点：** 临时端口冲突；缺少提供者缓存；核心启动失败或中途退出；真实节点可能共享公网 IP；主进程异常退出后的监督清理。

**验收结果：** `PLAYWRIGHT_BROWSERS_PATH=/private/tmp/x-follow-browsers npm test`，8/8 通过。真实 Homebrew 快照启动识别 76 个候选节点，未向 X 发出测试请求。独立审查发现的默认应用直连入口已关闭；提供者元数据需单独读取的问题已由真实核心端到端验收覆盖。
